2. Click "Sign up"
3. Create account
4. Verify email

### Step 2: Create Repository
1. Click "+" menu → "New repository"
2. Name: `customer-success-analytics`
3. Description: `Professional CS analytics toolkit`
4. Make it **Public**
5. Add README (check box)
6. Add MIT License
7. Click "Create repository"

For each file:
1. Click "Add file" → "Create new file"
